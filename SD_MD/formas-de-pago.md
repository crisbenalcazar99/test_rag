# Formas de Pago en Security Data

## Métodos de pago aceptados por Security Data

Security Data acepta varios métodos de pago para la compra y renovación de firma electrónica y demás servicios, para que el cliente use el que más le convenga:

- **Tarjeta de crédito o débito:** se aceptan todas las tarjetas.
- **Pago en línea:** pago con tarjeta de crédito Visa o Mastercard desde el portal de Security Data.
- **Transferencia bancaria.**
- **Depósito bancario.**
- **Pago en instituciones bancarias del Ecuador:** mediante banca móvil, banca web o en agencias a nivel nacional.
- **PayPal.**
- **Western Union.**

## Forma de pago según el canal de compra

- **Compra en línea (portal o app):** el método de pago se elige al final del proceso, después de la validación de identidad. El pago en línea acepta tarjetas de crédito Visa y Mastercard.
- **Servicio express presencial en oficinas:** el pago se realiza únicamente con tarjeta de crédito o débito.
