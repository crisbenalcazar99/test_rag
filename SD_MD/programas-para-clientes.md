# Programas y Facilidades para Clientes

## Plan de Referidos (Security Points)
Convierte tus acciones en recompensas. Acumula puntos al referir amigos o usar los productos de Security Data y canjéalos por premios.

**Hazlo en 3 sencillos pasos:**
1. Inicia sesión en tu portal de Security Data.
2. Selecciona Security Points en el menú lateral izquierdo.
3. Para referir a tus amigos, copia y comparte el enlace único.

Al usar los diferentes servicios de Security Data también se acumulan puntos.
